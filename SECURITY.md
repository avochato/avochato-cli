# Security Policy

Please do not report security issues in public GitHub issues.

Email **cli@avochato.com** with a description of the issue, steps to reproduce, and the CLI version (`avochato --version`). You can also use GitHub's private [Report a vulnerability](https://github.com/avochato/avochato-cli/security/advisories/new) form on this repository.

If you think an Avochato API credential has been exposed, rotate it in the Avochato web app under **Settings > API Access**.
